HTML

Belajar HTML Pemula

HTML (HyperText Markup Language) adalah bahasa dasar untuk membuat struktur halaman website. HTML bukan bahasa pemrograman, melainkan bahasa markup yang memberi tahu browser bagaimana menampilkan teks, gambar, tombol, dan elemen lainnya.

CSS

Belajar CSS Pemula

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan halaman web. Jika HTML adalah kerangka/struktur, maka CSS adalah desainnya (warna, ukuran, jarak, tata letak).

JavaScript

Belajar JavaScript Pemula

vaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi hidup dan interaktif. Jika HTML berfungsi sebagai kerangka dan CSS sebagai pengatur tampilan, maka JavaScript berperan mengatur perilaku sebuah website. Dengan JavaScript, sebuah halaman web tidak hanya menampilkan informasi secara statis, tetapi juga dapat merespons tindakan pengguna seperti klik tombol, pengisian form, atau pergerakan mouse.
